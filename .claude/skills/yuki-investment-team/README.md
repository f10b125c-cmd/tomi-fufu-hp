# yuki-investment-team

個人投資家（日本株・中長期／高配当／個別株／スイング／一部信用）向けの
「AI投資会議」スキル。Claude Codeのスキルとして動作する。

## これは何をするものか

銘柄をAIに選ばせたり、売買を実行させたりするものではない。
1つの銘柄について、6つの異なる専門的視点（決算・バリュエーション・
テクニカル・反対意見・リスク・統合）から分析させ、**人間が最終判断するための
投資会議レポート**を、毎回同じ形式・同じ品質で作成する。

```
調べる → 疑う → リスクを計算する → 記録する → 判断する
```

という投資プロセスを再現することが目的。

## 絶対にしないこと

- 証券口座へのアクセス／売買注文／自動発注
- 最終的な売買決定（命令形の指示）
- 存在しない数字の補完、根拠のない株価予想

最終決裁は必ず人間。詳細は `references/investment-policy.md` を参照。

## 使い方

Claude Codeのセッションでこのリポジトリを開いている状態で、次のように依頼する。

```
三菱UFJフィナンシャル・グループ（8306）について投資会議して。
3,700円で100株、現物での購入を検討しています。
```

または、より詳しい指定：

```
日本株〇〇について投資会議を実施してください。
◯◯円で100株購入を検討しています。
決算、バリュエーション、日足・週足・月足、反対意見、ポジションリスクを
分析し、最終的に投資会議レポートにまとめてください。
特にレッドチームは強気意見に迎合せず、独立して買わない理由を
最低3つ出してください。
```

保有銘柄の四半期レビューやトレード日誌の記録も同様に自然文で依頼できる
（`SKILL.md`の「購入後」「四半期レビュー」を参照）。

```
    technical-analyst.md      # 月足・週足・日足分析
    red-team.md                # 買わない理由・弱気シナリオ（最重要）
    risk-manager.md            # ポジションサイズ・最大損失
    investment-chair.md        # 全担当の統合

  README.md
  HANDOVER.md
```

## Phase 1（現在）の範囲

以下の6役のみ。

1. earnings-analyst
2. valuation-analyst
3. technical-analyst
4. red-team
5. risk-manager
6. investment-chair

`shareholder-return` 等の追加ロールはPhase 2以降、必要になった場合のみ追加する
（`SKILL.md`末尾を参照）。

## 既知の制約

- このスキルはリアルタイムのローソク足チャートを直接描画・解析する機能を
  持たない。月足・週足の詳細なテクニカル分析の精度を上げたい場合は、
  チャート画像やOHLCデータを会話に添付することを推奨する
- Web検索で取得できるPER/PBR/ROE・配当利回り等の指標は、取得元や
  取得タイミングによって数値が食い違うことがある。このスキルは
  食い違いを検出して両論併記する設計だが、最終的な数値確認は
  証券会社の取引画面や会社IRページで行うこと

詳細な開発経緯・テスト結果は `HANDOVER.md` を参照。
