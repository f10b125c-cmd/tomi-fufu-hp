# 投資会議レポート 出力定義（output-template）

`investment-chair` が最終レポートを作成する際、以下の17項目を
**この順番通りにすべて**含める。省略・順序変更・統合は禁止。
実際の見出し・レイアウトは `templates/investment-meeting.md` を使う。

| # | 項目 | 内容・注意点 |
|---|---|---|
| 1 | 銘柄・コード | 会社名と証券コード（例：三菱UFJフィナンシャル・グループ 8306） |
| 2 | 現在株価 | 取得日時を必ず併記。データソース元も書く |
| 3 | 検討価格 | ユーザーが提示した購入検討価格 |
| 4 | 株数 | ユーザーが提示した株数。現物/信用の別も明記 |
| 5 | 決算評価 | `earnings-analyst` の分析結果の要約。一次資料の発表日を明記 |
| 6 | バリュエーション評価 | `valuation-analyst` の分析結果の要約。PER/PBR/ROE/配当利回り等 |
| 7 | チャート評価 | `technical-analyst` の分析結果の要約。月足・週足・日足それぞれに言及 |
| 8 | レッドチームの反対意見 | `red-team` の意見を**そのまま・最低3項目**掲載。要約・弱体化しない |
| 9 | リスク評価 | `risk-manager` の分析結果。投資金額・想定損失の数値を含む |
| 10 | 買い材料3つ | ポジティブ要因を3つ、箇条書きで簡潔に |
| 11 | 見送り材料3つ | ネガティブ要因を3つ、箇条書きで簡潔に（red-teamの意見と重複してよい） |
| 12 | 打診候補価格 | 少量から入る場合の候補価格帯（断定的な「買い時」表現は避ける） |
| 13 | 追加候補価格 | 打診後に買い増しを検討しうる価格帯（あれば） |
| 14 | 上抜け確認価格 | 上昇トレンド継続の確認となりうる価格（あれば） |
| 15 | 前提崩壊価格または条件 | 投資仮説が崩れると判断できる価格、またはファンダメンタルズ上の条件 |
| 16 | 最大想定損失 | `risk-rules.md` の計算式に基づく金額。前提未入力なら「算出不可」 |
| 17 | 最終判定 | 🟢 候補 / 🟡 待つ / 🔴 見送り のいずれか一つ。理由を1〜2文で添える |

## 最終判定の目安（断定ではなく判断材料）

- 🟢 候補：買い材料がレッドチームの懸念を明確に上回り、打診候補価格の水準に
  現在株価が近い、または到達している
- 🟡 待つ：判断材料が不足している、または打診候補価格にまだ到達していない、
  もしくは強気・弱気が拮抗していて現時点では判断がつかない
- 🔴 見送り：レッドチームが指摘する前提の弱さ・リスクが買い材料を上回る、
  または想定損失がユーザーの許容度に対して過大と考えられる

判定は**あくまで会議の結論案**であり、「買え」「売れ」という命令ではない。
必ず末尾に人間の最終決裁欄（決裁者・日付・実際の判断・メモ）を設ける。

## レポート末尾に必須の免責

すべてのレポートの末尾に以下の趣旨の文を入れる。

> 本レポートはAIによる情報整理・分析であり、投資助言・勧誘ではありません。
> 数値は記載時点の情報に基づき、誤りや更新の遅れが含まれる可能性があります。
> 売買の最終判断は、必ずご自身の責任で行ってください。
