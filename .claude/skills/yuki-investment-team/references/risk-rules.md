# リスク計算ルール（risk-rules）

`risk-manager` はこのファイルの計算式・警告基準を必ず使う。
数値の創作は禁止。入力が無い項目は計算せず「算出不可（〇〇が未入力）」と書く。

## 1. 基本計算式

購入価格・株数が与えられたら、必ず以下を計算しレポートに明示する。

```
投資金額 = 購入価格 × 株数
```

購入価格・株数・前提崩壊価格（investment thesisが崩れると判断する価格）が
すべて与えられたら、必ず以下を計算する。

```
想定損失 = (購入価格 − 前提崩壊価格) × 株数
```

- 前提崩壊価格が購入価格より高い場合（＝計算上ありえない入力）は、その旨を指摘し
  再確認を求める。
- 前提崩壊価格が未定の場合は、想定損失を「算出不可」とし、
  `red-team`・`technical-analyst` の分析を踏まえて前提崩壊価格の候補を
  提案してよい（ただし断定はせず「候補」と明記する）。

## 2. ポジションサイズの観点

以下は分かる範囲でコメントする（保有資産全体の情報が無ければ無理に推定しない）。

- 投資金額が、ユーザーが言及した保有資産・現金余力に対してどの程度の比率か
- 同一銘柄・同一セクターへの集中度（ユーザーが既存保有を共有している場合のみ）
- 分割エントリー（打診→本格買い）の余地

## 3. 信用取引の場合の追加警告（必須）

信用取引が示唆・明言された場合、`risk-manager` は以下を**すべて**含める。
一つでも省略してはならない。

1. **元本を超える損失の可能性**：信用取引はレバレッジを伴うため、
   投資金額（証拠金）を超える損失が発生しうる。
2. **追証（追加保証金）リスク**：株価が逆行し委託保証金率が
   維持率を下回ると追証が発生し、期日までに入金できなければ
   強制決済（ロスカット）される可能性がある。
3. **金利・貸株料等のコスト**：信用買いの金利、信用売りの貸株料など、
   保有期間に応じたコストが発生し、中長期保有ほど累積負担が大きくなる。
4. **返済期限**：制度信用取引には返済期限がある（一般信用は銘柄・証券会社による）。
   期日到来時に強制決済されるリスクを明記する。
5. **急変動時のリスク**：決算発表・市場急変時に値幅制限（ストップ安等）で
   決済ができず、損失が想定以上に拡大するリスク。

これらは現物取引よりも**厳しい表現・警告の優先度で**記述すること
（「念のため」ではなく「必ず理解した上で判断してください」という書き方にする）。

## 4. 書いてはいけないこと

- 「この価格まで下がることはない」等、下落を否定する断定
- 「損切りラインはここで十分」等、リスク管理の妥当性を保証する表現
- ポジションサイズや損切りラインそのものの「指示」（あくまで計算結果と
  論点の提示に留め、決定はユーザーに委ねる）
