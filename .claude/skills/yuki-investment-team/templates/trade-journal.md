# トレード日誌テンプレート

購入・売却が実行された後、以下の形式で記録する。このスキルは記録の整形を
支援するのみで、売買の実行や継続保有・決済の助言は行わない。

## 記入項目

```yaml
date:              # 記録日 YYYY-MM-DD
ticker:            # 証券コード
company:           # 会社名
entry_price:       # エントリー価格（円）
shares:            # 株数
cash_or_margin:    # 現物 / 信用（制度・一般の別）
thesis:            # 投資仮説（なぜ買ったか。投資会議レポートの買い材料を要約）
risks:             # 主なリスク（投資会議レポートのレッドチーム意見・見送り材料を要約）
invalidation:      # 前提崩壊価格または条件
profit_condition:  # 利益確定・追加購入を検討する条件
next_earnings:     # 次回決算発表予定日
```

## 記入例（形式のみ・数値はダミー）

```yaml
date: 2026-09-05
ticker: "0000"
company: サンプル株式会社
entry_price: 1350
shares: 100
cash_or_margin: 現物
thesis: 高配当・増配継続を評価。投資会議レポート（2026-09-05作成）の買い材料を参照。
risks: 主力事業の需要鈍化懸念。投資会議レポートのレッドチーム意見を参照。
invalidation: 1200円割れ、または通期減配発表
profit_condition: 1500円到達、または次回決算での上方修正
next_earnings: 2026-11-XX（予定・要確認）
```

## 運用ルール

- 1件のエントリーにつき1レコード。同一銘柄への買い増しは別レコードとして追記する
- `thesis` / `risks` / `invalidation` は、その売買の元になった投資会議レポートの
  内容と矛盾しないようにする（レポートを書き換えるのではなく要約・引用する）
- ここに記載した情報は `templates/quarterly-review.md` での再評価の基礎資料になる
