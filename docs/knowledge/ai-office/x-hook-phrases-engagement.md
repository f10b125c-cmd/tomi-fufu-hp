# X（旧Twitter）で使われる「伸びる書き出し」フレーズ集（要注意情報）

- **出典**: ユーザー提供のテキスト（URL・投稿者情報なし、2026年8月25日受領）
- **内容**: X投稿の冒頭で使われる、心理トリガーを利用した10個の「フック」文言と、それぞれが効く理由の解説
- **用途**: [X運用×AI記事執筆術のナレッジ](./x-algorithm-article-writing.md)と同系統。**自社発信でそのまま多用するものではなく、「読者心理を操作する手口を知っておく」ための参考情報**として記録する

## ⚠️ 先に注意点

このリストは全10項目のうち複数が、読者に事実と異なる印象を与えたり、行動を急かしたりする**ダークパターン的なコピーライティング手法**に分類される。

- **④「※これあとで消す」**は偽の希少性（フェイクスケアシティ）を作り出す典型例。実際に消す運用にしないと、読者の信頼を損なう「嘘の緊急性」になる。
- **⑨「これやってないアカウントは全部伸びてない」**は根拠のない断定で不安を煽る手法で、事実確認なしに使うと誇大・不正確な情報発信になりかねない。
- **①⑦**の損失回避・注意喚起も、事実に基づかない誇張で使えば不安商法に近づく。
- 自社のAIオフィスで発信のトーン・ルール（`ai-shain-7nin-claude-code.md` でいう `knowledge/ng-list.md` 相当）を作る際は、**この種のフレーズを無条件で許可リストに入れず、事実に基づく場合のみ・誇張なしで使う旨を明記する**ことを推奨する。

以上を踏まえた上で、「なぜ効くとされているか」の心理的メカニズムの整理は、コンテンツ企画のレビュー観点（校閲担当のチェック項目など）として活用できる。

## フレーズ一覧と効くとされる理由

| # | フレーズ例 | 効くとされる理由 |
|---|---|---|
| ① | 「これ知らないと一生損する」 | 損失回避バイアス。得られる利益より失う恐怖の方が強く働き、反射的に読ませる |
| ② | 「これ9割の人が間違えてる」 | 大多数派に該当する不安＋「自分は例外」と思う層の両方を巻き込める |
| ③ | 「これあんま言いたくないんだけど」 | 本音・裏情報感を演出し、特別感（インサイダー感）で引き込む |
| ④ | 「※これあとで消す」 | 希少性・緊急性の演出。**実際に消す運用が前提**（でないと虚偽の緊急性になる） |
| ⑤ | 「フォロワー100人の時にやること」 | 数字と具体性が信頼感・再現性の印象を強める |
| ⑥ | 「※初心者の人は見なくていいです」 | 逆説的に「自分に関係あるかも」と初心者ほど読んでしまう |
| ⑦ | 「〇〇してる人、マジで今すぐやめた方がいい」 | 注意喚起・危機感で「自分ごと」として読ませる |
| ⑧ | 「たった1行変えただけでインプが10倍になった」 | 短期間・小さな労力で大きな変化という即効性の魅力 |
| ⑨ | 「これやってないアカウントは全部伸びてない」 | 断定表現による危機感。逃げ場のなさを演出 |
| ⑩ | 「※ブクマ必須」 | 有益性の予告。**中身が薄いと逆効果**になるため多用注意 |

原文コメント: 「ビジネス系以外のアカウントにも転用できる」とされ、ジャンルを問わず使える汎用フックとして紹介されていた。

## AIオフィスへの適用メモ

- コンテンツ生成AI（[AI社員7人体制](./ai-shain-7nin-claude-code.md)でいう「ライター担当」）にこの種のフックを機械的に使わせると、事実確認なしの誇張表現が量産されるリスクがある。`ng-list.md` や校閲担当のチェック項目に「根拠のない断定表現」「偽の緊急性・希少性」を明示的に加えることを検討する。
- 逆に、**自社が受け取る側として**、SNSで見かける煽り文句を見抜くチェックリストとしても使える（③⑨のような文言が出てきたら根拠の有無を確認する、など）。
