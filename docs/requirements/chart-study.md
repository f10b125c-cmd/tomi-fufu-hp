# 株価チャート学習アプリ 要件定義書（v0.1 ドラフト）

- 作成日: 2026-11-10
- ステータス: ドラフト（レビュー待ち）
- 配置: とみ夫婦サイト内 `/money/chart-study`

---

## 1. 背景・目的

「投資・NISA」ページで発信している我が家の投資経験を、**実際に手を動かして学べる形**にする。
NISA や個別株を始めたものの「チャートの見方がよくわからない」という初心者（まずは自分たち・家族）が、
遊び感覚でチャートの基本を身につけられるようにする。

### ゴール
- ローソク足・移動平均線・出来高などの**基本を自分の言葉で説明できる**ようになる
- 代表的なチャートパターンを**見て気づける**ようになる
- 「チャートだけで未来は当たらない」ことも含め、**リスクを体感的に理解する**

### やらないこと（スコープ外）
- 特定銘柄の売買推奨・投資助言（金融商品取引法上の投資助言に当たる表現は避ける）
- 実際の証券口座との連携・実売買
- リアルタイム株価の配信

## 2. 想定ユーザー

| ペルソナ | 状況 | 求めること |
|---|---|---|
| 投資初心者（自分・家族） | NISA で積立を始めた／個別株に興味あり。チャート用語はほぼ知らない | 難しい言葉なしで、少しずつ・スマホで・すき間時間に学びたい |

- 主な利用端末: **スマートフォン**（PC でも使える）
- 1 回の利用時間: 3〜10 分程度を想定

---

## 3. 機能要件

学習は 4 つのモードで構成する。初心者が迷わないよう、おすすめ順は
**① レッスン → ② 用語クイズ → ③ チャート当てクイズ → ④ 仮想トレード**。

### 3.1 ① パターン解説レッスン
| ID | 要件 | 優先度 |
|---|---|---|
| L-1 | レッスン一覧を表示し、順番に進められる | Must |
| L-2 | 各レッスンは「図解チャート＋短い説明（3〜5 画面）＋確認問題 1〜2 問」で構成 | Must |
| L-3 | レッスンの完了状態を保存し、一覧に ✓ を表示 | Must |
| L-4 | チャート上の注目ポイントをハイライト表示（例: ヒゲ、ゴールデンクロス地点） | Should |

初期レッスン案（MVP は ★ の 6 本）:
1. ★ ローソク足の読み方（始値・高値・安値・終値、陽線・陰線、ヒゲ）
2. ★ トレンドとは（上昇・下降・横ばい）
3. ★ 移動平均線（5 日・25 日・75 日）
4. ★ ゴールデンクロス／デッドクロス
5. ★ 出来高の見方
6. ★ サポートライン・レジスタンスライン
7. ダブルボトム／ダブルトップ
8. 三尊（ヘッドアンドショルダー）
9. 窓（ギャップ）
10. RSI・MACD の基礎

### 3.2 ② 用語クイズ
| ID | 要件 | 優先度 |
|---|---|---|
| Q-1 | 4 択問題を 1 セット 5〜10 問出題 | Must |
| Q-2 | 回答直後に正誤と短い解説を表示 | Must |
| Q-3 | カテゴリ（チャート用語／株の基本用語：PER・PBR・配当利回り・出来高 等）で絞り込み | Should |
| Q-4 | 間違えた問題を「復習リスト」に入れて再出題 | Should |

### 3.3 ③ チャート当てクイズ
| ID | 要件 | 優先度 |
|---|---|---|
| C-1 | チャートを途中まで表示し「この後 上がる／下がる」を選ばせる | Must |
| C-2 | 回答後に続きのチャートをアニメーションで表示し、正誤を判定 | Must |
| C-3 | 「どこに注目すべきだったか」の解説を表示（パターン名・根拠） | Must |
| C-4 | 正答率を記録・表示 | Must |
| C-5 | 「チャートの形だけでは当たらないこともある」旨を必ず表示し、パターン通りにならない問題も一定割合混ぜる | Must |
| C-6 | 難易度（やさしい＝典型パターン／ふつう／むずかしい）選択 | Could |

### 3.4 ④ 仮想トレード練習
| ID | 要件 | 優先度 |
|---|---|---|
| T-1 | 仮想資金 100 万円でスタート | Must |
| T-2 | 過去チャートを「次の日へ」ボタンで 1 本ずつ進める | Must |
| T-3 | 買う／売る（全部・半分）の操作ができる。手数料は 0 円 | Must |
| T-4 | 損益・保有株数・残高をリアルタイム表示 | Must |
| T-5 | 終了時に成績サマリー（損益率、売買回数、「何もしなかった場合」との比較） | Must |
| T-6 | 売買ポイントをチャート上にマーク表示し振り返りできる | Should |
| T-7 | 過去の成績履歴の一覧 | Could |

### 3.5 共通
| ID | 要件 | 優先度 |
|---|---|---|
| X-1 | 学習トップ画面（4 モードへの入口＋進捗サマリー） | Must |
| X-2 | 進捗（レッスン完了、正答率、トレード成績）を**ブラウザ内（localStorage）に保存**。ログイン不要 | Must |
| X-3 | 進捗リセット機能 | Must |
| X-4 | 免責表示（教育目的であり投資助言ではない／架空データである旨）を各モードに表示 | Must |
| X-5 | サイトのヘッダー・フッター・デザイン（ブランドカラー）を踏襲 | Must |
| X-6 | 「投資・NISA」ページから学習トップへの導線 | Must |
| X-7 | 用語にタップで説明が出るツールチップ | Should |

## 4. データ要件

段階的に対応する。

### Phase 1（MVP）: 架空データ
- 学習用に**プログラムで生成した OHLCV（始値・高値・安値・終値・出来高）データ**を使用
- パターン（ダブルボトム、ゴールデンクロス等）を意図的に埋め込んだシナリオを作れる生成ロジックを用意
- 乱数シード固定で、同じ問題は毎回同じチャートになるようにする
- 銘柄名は架空（例: 「とみ商事」）
- データはリポジトリ内の JSON または実行時生成。サーバー・DB 不要

### Phase 2: 実在銘柄の過去データ
- 日本株・米国株の代表的な銘柄の**過去の日足**を使用
- 着手前に確認すること:
  - データ提供元の**利用規約（再配布・Web 表示の可否、商用利用の扱い）**
  - 費用（無料枠の範囲）
  - 取得方法（ビルド時に取得して静的 JSON 化するか、API 経由か）
- クイズでは銘柄名・日付を伏せて出題し、回答後に明かす

## 5. 非機能要件

| 項目 | 要件 |
|---|---|
| 対応端末 | スマホ（幅 360px〜）を最優先。PC・タブレットでも崩れない |
| 操作性 | チャートはタップ・スワイプで操作可能。ボタンは指で押しやすいサイズ（44px 以上） |
| 性能 | 初回表示 3 秒以内（4G 回線想定）。チャート描画はカクつかない |
| アクセシビリティ | 陽線・陰線を**色だけで区別しない**（塗りつぶし／白抜き等も併用）。コントラスト比 WCAG AA |
| 配色 | 日本式（陽線＝赤、陰線＝青/緑）を基本とする（※設定で切替は Could） |
| 認証 | 不要（MVP） |
| 費用 | 月額 0 円で運用できること（Phase 1） |
| 法令・表記 | 免責表示を常設。特定銘柄の推奨と取れる表現をしない |

## 6. 技術方針（案）

- 既存の **Next.js（App Router）＋ Tailwind CSS** サイトにページとして追加
  - ※このリポジトリの Next.js は新しいバージョンのため、実装前に `node_modules/next/dist/docs/` を確認する
- ルーティング案:
  - `/money/chart-study` … 学習トップ
  - `/money/chart-study/lessons/[slug]` … レッスン
  - `/money/chart-study/quiz/terms` … 用語クイズ
  - `/money/chart-study/quiz/chart` … チャート当てクイズ
  - `/money/chart-study/trade` … 仮想トレード
- チャート描画ライブラリ候補（実装前に比較して決定）:
  - **lightweight-charts**（TradingView 製、ローソク足に特化・軽量） … 第一候補
  - Recharts / 自作 SVG … レッスンの図解など単純な図向け
- 状態保存: localStorage（将来ログイン機能を付ける場合は Supabase 等を検討）
- 教材データ（レッスン本文・問題）は TypeScript／JSON ファイルで管理し、コード変更なしで追加しやすくする
