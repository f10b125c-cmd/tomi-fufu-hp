# 【引き渡し用】アイコン画像生成（①うさねこ占い／②こんこん占い）

> やり方：ツール（ChatGPT Image / Codexの画像生成機能など）に、
> 1. 対応する参考画像（`knowledge/assets/icons/`内のPNG）を添付
> 2. 下のプロンプトをそのまま貼る
> の2点セットで渡してください。

---

## ①うさねこ占い

**添付する参考画像**：`knowledge/assets/icons/usaneko-concept.png`

**貼るプロンプト**
```
添付は簡易ラフです。このキャラクターとテイストを元に、もっと綺麗に仕上げてください。

白いうさぎと黒猫が半分ずつ合わさったような、丸くてふわふわしたキャラクター。
目は大きく優しい印象。背景はシンプルな紺〜紫のグラデーション。
SNSアイコンとして視認性が高いフラットデザイン。正方形、1:1。
```

---

## ②こんこん占い

**添付する参考画像**：`knowledge/assets/icons/konkon-concept.png`

**貼るプロンプト**
```
添付は簡易ラフです。このキャラクターとテイストを元に、もっと綺麗に仕上げてください。

オレンジと白の狐のシルエット、片目を細めた少しシニカルな表情。
太めの輪郭線で視認性の高いフラットデザイン。正方形、1:1。
```

---

## 受け取り後の使い方
1. 生成された画像をダウンロード
2. Threadsの該当アカウントのプロフィール画像として設定
3. 完了したら `day1-account-setup.md` の「アイコン」欄を「✅ 本番アイコン設定済み」に更新（私に一言伝えてもらえれば反映します）
