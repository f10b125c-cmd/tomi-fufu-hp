# Day2 初投稿ドラフト（シート04・05相当）

参照: [[../threads-uranai-7days-0to1-monetization#Day 2｜初投稿を出して、バズらせる]]

前提：Day1のアカウント作成・アイコン設定が終わってから投稿する（投稿はまだ出さない）。

## 投稿の型（おさらい）
1. 1行目＝フック（興味づけ。ただの日常ではなく「おや？」と思わせる）
2. 2〜数行＝比べられない一点（実話）を短く。リアルすぎる生活情報（年齢・職業の詳細）は避ける
3. いまやっていること（無料鑑定の匂わせ）
4. CTA＝「生年月日をコメントに置いていって」だけの、その場で完結する行動指示（プロフ遷移・リンクは求めない）

投稿時間の目安：6時／12時／18〜21時

---

## ①うさねこ占い（柔らかいトーン）

### 本命案
```
また、ゼロから始めることにしました。

インスタで2.7万人と繋がっていたのに、
ある日、身に覚えのない理由でアカウントごと消えたんです。
積み上げてきたものが、一瞬でゼロになる感覚。

しんどかったけど、気づいたこともあって。
本当に繋がりたい人とは、数字なんて関係なく繋がれるって。

だから今度は、ここで。
夜だけ、うさぎとねこの間で生きてます🐰🐈‍⬛
占い、少しやってます。

気になる人、コメントに生年月日だけ置いてって。
```

### 1行目バリエーション（伸びなかった時の差し替え用・Day2の3段構え①用）
- 「もう一回、ゼロからやることにしました。」
- 「実は、アカウントが一つ消えました。」
- 「うさぎとねこの間くらいの生き物です。占います。」

## ②こんこん占い（辛口トーン）

### 本命案
```
正直に言う。

2.7万人フォロワーがいたインスタを、
身に覚えのない理由で一晩で消された。
何も悪いことしてないのに、です。

優しい言葉なんて要らない。
私は、本当のことしか言わない。
それだけ。

生年月日、コメントに置いてって。視るから。
```

### 1行目バリエーション（伸びなかった時の差し替え用）
- 「本音しか言わない狐です。」
- 「積み上げたもの、一晩で消えたことある人いる？」
- 「優しい嘘は、もういらない。」
